# Benmark's Portfolio

A simple portfolio homepage built with HTML, CSS, and JavaScript.

## Files
- `index.html` — homepage content and project cards
- `styles.css` — layout, colors, and responsive design
- `script.js` — small JavaScript behavior (current year)

## Publish with GitHub Pages
1. Upload these files to the **root** of your `Portfolio-` repository.
2. Keep your existing `Online Catalog` folder and its files.
3. Open **Settings → Pages** in GitHub.
4. Set the publishing source to the `main` branch and `/(root)`.
5. Visit `https://benmark1020.github.io/Portfolio-/`.

## Add another project
Copy one of the `<article class="project-card"> ... </article>` blocks in `index.html`.
Change the project title, description, tags, live website link, and source-code link.

## Suggested long-term organization
For bigger projects, create one repository per project:
- `online-catalog`
- `validation-form`
- `personal-portfolio`

Use this repository as the homepage that links to all your projects.
